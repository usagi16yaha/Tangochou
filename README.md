# 単語帳アプリ

PCとスマホで使える単語帳アプリです。

## 機能

- 問題と答えを自由に登録・編集・削除できる
- スワイプ（スマホ）またはスペースキー（PC）で答えを表示
- 苦手な単語だけを集めて復習できる「苦手モード」
- 正解率を表示する結果画面

## 操作方法

### スマホ
| 操作 | 効果 |
|---|---|
| 上スワイプ（問題画面） | 答えを表示 |
| 上スワイプ（答え画面） | 次の問題へ（わかった） |
| 「もう一度」ボタン | 苦手リストに追加して次へ |

### PC
| 操作 | 効果 |
|---|---|
| スペースキー（問題画面） | 答えを表示 |
| スペースキー（答え画面） | 次の問題へ（わかった） |
| 「もう一度」ボタン | 苦手リストに追加して次へ |

## セットアップ

Node.js をインストール後、以下を実行してください。

```
npm install
node server.js
```

ブラウザで `http://localhost:3000` を開くと使えます。

## 技術構成

- フロントエンド：HTML / CSS / JavaScript
- バックエンド：Node.js + Express
- データベース：SQLite（sql.js）
